Class TrainARTrainingsWindow

Namespace
Editor.Scripts

The TrainAR Trainings tab (docked next to the simulator): one list with a box per training (preview with the round expert, name, description). Every box can be opened in the authoring tool, edited, duplicated and deleted; new trainings are added at the bottom. All trainings are part of the build and shown on the home screen; previews are rendered by every build.
